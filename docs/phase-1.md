# Phase 1 — Project Scaffold

## Scope

Establish the backend and frontend project skeletons with no business logic:

- FastAPI app with configuration management (`.env` / `.env.example`), CORS, logging, global
  exception handling, a health endpoint, and the base API folder structure.
- Static HTML/CSS/JS frontend shell: a landing/dashboard page that calls the backend health
  endpoint to confirm connectivity.

## Explicitly Out of Scope

- Database
- Authentication
- AI
- Telephony
- Appointments
- Notifications

These are addressed in later phases.
